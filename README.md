# Paradise Nursery - E-Commerce Plant Shopping Application

Paradise Nursery is an intuitive e-commerce web application designed for plant lovers. Browse a curated collection of house plants, view details, and manage your shopping cart effortlessly.

## Features
- **Landing Page:** Welcomes users with a background image and a "Get Started" button to explore plants.
- **Product Listing:** Display plants organized by categories with details such as name, image, and cost.
- **Shopping Cart Management:**
  - Add items to the cart.
  - Dynamically update product quantity directly in the cart.
  - Automatically calculate subtotal and total costs.
  - Remove items from the cart.
  - Track total item count on the navigation bar badge.
- **About Us Section:** Details about Paradise Nursery's mission and background.

## Tech Stack
- **Frontend:** React.js, Redux Toolkit, CSS3
- **Build Tool:** Vite
